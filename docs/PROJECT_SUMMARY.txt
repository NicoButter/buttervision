================================================================================
  ⚡ INICIO RÁPIDO
================================================================================

1️⃣  INSTALACIÓN (Linux/Mac):
    $ bash install.sh cuda118        # Para CUDA 11.8
    $ source venv/bin/activate

    Windows:
    > install.bat cuda118
    > venv\Scripts\activate.bat

2️⃣  LANZAR APLICACIÓN:
    $ python main.py --medvram       # GPU 4-6GB
    $ python main.py --lowvram       # GPU < 4GB
    $ python main.py                 # GPU 8GB+

3️⃣  ABRIR EN NAVEGADOR:
    http://localhost:7860

4️⃣  GENERAR PRIMERA IMAGEN:
    - Prompt: "a beautiful mountain landscape, sunset"
    - Click "Generate"
    - ¡Listo!


================================================================================
  ✨ CARACTERÍSTICAS IMPLEMENTADAS
================================================================================

✅ Text-to-Image               Generación desde texto
✅ Image-to-Image              Transformación de imágenes
✅ Soporte para LoRAs          Hasta 2 LoRAs simultáneos
✅ Múltiples Schedulers        DPM++, Euler, DDIM, KDPM2, etc.
✅ Optimización Low-VRAM       Funciona con GPUs de 4GB+
✅ xformers Integration        Ahorro significativo de VRAM
✅ Float16 Support             Reduce uso de memoria a la mitad
✅ Attention Slicing           División de cálculos en chunks
✅ VAE Slicing                 Procesamiento en batches
✅ CPU Offloading              Para VRAM extremadamente baja
✅ Auto-save Images            Con metadata (seed, prompt, etc.)
✅ Múltiples Modelos           Cualquier modelo de HuggingFace
✅ Seeds Reproducibles         Control total de generación
✅ Negative Prompts            Mayor control sobre resultados
✅ Batch Generation            Múltiples imágenes simultáneas
✅ Interfaz Moderna            Gradio responsive y limpia
✅ CLI Arguments               Control completo por línea de comandos
✅ Authentication Support      Opcional (--auth)
✅ Share Links                 Gradio public URLs (--share)


================================================================================
  🔧 COMANDOS ÚTILES
================================================================================

# Inicio básico
python main.py

# Optimizaciones según GPU
python main.py --lowvram          # < 4GB VRAM
python main.py --medvram          # 4-6GB VRAM
python main.py                    # 6GB+ VRAM

# Compartir públicamente
python main.py --share

# Con autenticación
python main.py --auth usuario:contraseña --share

# Modelo diferente
python main.py --model "stabilityai/stable-diffusion-2-1"

# Cambiar puerto
python main.py --port 8080

# Test sin UI
python test_generation.py

# Verificar CUDA
python -c "import torch; print(torch.cuda.is_available())"
